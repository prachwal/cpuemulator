# Coding Conventions

## C#/.NET

- .NET 8
- nullable enabled
- implicit usings enabled
- jedna klasa na plik
- jawne modele danych
- brak magic numbers
- prefer immutable models
- male metody
- male klasy
- SOLID

## Testy

- MSTest
- FluentAssertions
- Moq
- testy dla logiki domenowej
- regression tests dla bugfixow

## Logowanie

- NLog
- brak Console.WriteLine w kodzie produkcyjnym

## Git

- male commity
- commit per feature/fix
- aktualizacja dokumentacji przy zmianie zachowania
